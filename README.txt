UHURU DIGITAL CONSULTATIONS — INVOICE BUILDER

FILES
- index.html
- style.css
- script.js

FEATURES
- Admin login
- LocalStorage database
- Create/edit invoices
- Add/remove unlimited line items
- Automatic subtotal, VAT/tax and total calculations
- Live invoice preview
- Browser Print / Save as PDF
- Company settings
- Logo upload stored in LocalStorage
- Appearance settings
- Saved invoice history
- JSON backup/export and import
- Change admin password

HOW TO USE
1. Keep all three files in the same folder.
2. Open index.html in Chrome, Edge or another modern browser.
3. Default password: admin123
4. Open Company Details and enter your business information.
5. Upload the UHURU logo.
6. Build an invoice.
7. Click "PDF / Print", then choose "Save to PDF" in the browser print dialog.

IMPORTANT
This is a local-first system. LocalStorage belongs to the browser/device being used. It is not a shared online database. Use Backup & Settings to export/import your data between devices.
